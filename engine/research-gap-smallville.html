Grammar of Meaning · the Research-Gap Engine

Research-Gap Demo — Smallville

The same instrument that reads a text for meaning, pointed instead at a research paper for its validity threats. Run blind — the scanner was not shown the earlier read or the meaning-gaps — against a 10-locus validity-threat taxonomy. The point: it finds genuine, defensible research gaps from a paper's own words, and for each one it names the experiment that would resolve it.

The paper: Park et al., Generative Agents: Interactive Simulacra of Human Behavior (“Smallville”), arXiv 2304.03442 — the generative-agents work Saquib flagged. Read in full; reasoned only from the text; the load-bearing constants and quotes were verified against the published PDF.

What it provesThree ways

1 · The right tool — it recovered what the meaning-instrument missed.

Run blind, the validity-threat scan independently surfaced the ablation confound (G2): the ablations were never re-simulated — every condition answered interviews off the full architecture’s memory stream, with access throttled only at Q&A time (§6.2). So “each component contributes critically to behavior” is measured on read-access, not lived behavior. The meaning-gap instrument missed this; the wild cold-read caught it; the research-gap taxonomy recovered it from the taxonomy alone — the right tool finds it by construction.

2 · The value-add — a discriminating experiment per gap (the “gloss → test” transform).

The science-engine doesn’t stop at interpreting the gap; it produces a specific runnable test and says what each outcome would mean — the thing a cold read does not do. That transform is the centerpiece below.

3 · Sharper than either prior read — the d = 8.16 measurement artifact.

The scan caught that the headline “eight standard deviations” uses TrueSkill’s posterior σ — the estimator’s uncertainty, which shrinks as you add comparisons — as the denominator of Cohen’s d, rather than the outcome SD, manufacturing the huge number; and that d doesn’t reproduce from the reported μ/σ (recomputes ≈ 12.2). The cold read said “d is suspiciously large”; the research-gap scan localized why the statistic is the wrong quantity.

The findingsSix ranked gaps

Each cites the paper’s own words. The first two are worked all the way to their discriminating experiment — the transform in action; the rest are the ranked validity threats the same scan produced.

G1The d = 8.16 measurement artifact

The headline effect size uses TrueSkill’s posterior σ (an estimator-uncertainty that shrinks with more comparisons) as Cohen’s d denominator — not the outcome SD — manufacturing “eight SD.” And d doesn’t reproduce from the reported μ/σ (recomputes ≈ 12.2).

Discriminating experiment

Recompute a distributional effect size — Cliff’s δ or CLES — on the raw rank matrix already collected. If the huge separation vanishes, the headline number was an artifact of the wrong denominator, not a real architecture-vs-baseline gap.

G2The ablation confound — behavior vs Q&A read-access

The ablations were never re-simulated: every condition answered off the full architecture’s memory stream, access throttled only at question time (§6.2). So “each component contributes critically to behavior” is measured on read-access, not lived behavior.

Discriminating experiment

Re-simulate each ablation end-to-end, K ≥ 5 seeds, and rank the behavior replays — not the interviews. If the gap collapses, the original result measured Q&A read-access, not the architecture’s effect on behavior.

G3Construct validity

“Believability” is operationalized as interview-answering — how the agent talks about itself — not as behavior. The metric may be measuring the narrator, not the architecture.

G4Emergence is n = 1

The emergent-behavior claims (the party, the diffusion of information) rest on a single run, with no control condition or null model to say what would happen by chance.

G5Retrieval magic-constants + the wrong forgetting form

The recency/importance/relevance constants (0.995, α=1, the 150 reflection threshold) carry the system with no derivation or robustness range — and the exponential recency decay is a form ACT-R’s memory theory would contest.

G6Irreproducible model

An unpinned gpt-3.5-turbo, no seed or temperature reported, and a single run — the result cannot be reproduced as specified.

Runner-up — strawman baselines. The “prior work” condition is the authors’ own fully-gutted system, and the human baseline is explicitly non-maximal — so the comparison is stacked before the architecture is tested.

Honest flagsWhat the scan says about itself (§13)

  • The d-arithmetic discrepancy is a doesn’t-reproduce flag, not a proven error — the d-scale is unstated.
  • The G2 / G4 re-simulation tests are expensive-but-decisive — and cost is the paper’s own stated blocker.
  • G3 / G5 assume a believability scorer cheap enough to run at sweep scale.
  • The ablation-confound and weak-baseline points are partly self-acknowledged by the authors (§6.2). The gap is that the headline framing (the abstract, the d=8.16, “more believable than human crowdworkers”) doesn’t carry those caveats.
