Research-Gap Demo — Smallville

Smallville is a tech paper — the LLM's home turf. We tested honestly (a fair-baseline run) whether a structured instrument beats a strong plain read at finding research gaps. It doesn't: a strong wild read finds the gap-list on its own. So the gaps are not the contribution. What a seeded, structured instrument adds — and a cold read cannot — is the rival model, the paradigm critique, and auditable disagreement. That's the honest claim, and it's what this page leads with.

A strong cold read already surfaces the believability-metric confound, the short-timescale scope, the floor-effect baseline — even the ablation confound. Gap-finding is not where structure wins. Here is what only the seeded instrument produced.

How Smallville programmed memory

retrieval = αrec·recency + αimp·importance + αrel·relevance  (all α = 1)  → min-max normalized
  • recency — an exponential decay, factor 0.995 (≈ 0.995time since last access): one decaying number.
  • importance — the LLM is asked to rate the memory's poignancy 1–10 (a one-shot self-rating).
  • relevance — cosine similarity of the memory's embedding to the current query.
  • reflection fires when the sum of importance scores of recent events exceeds 150.

What the seeded ACT-R critic said — the validated human form

Human declarative memory has a 50-year-validated model — ACT-R base-level activation (Anderson & Schooler 1991; power-law of forgetting back to Ebbinghaus): Bᵢ = ln( Σⱼ tⱼ⁻ᵈ ), with attention added as Aᵢ = Bᵢ + Σⱼ Wⱼ·Sⱼᵢ. Smallville's form is wrong in three structural ways:

  1. Shape — exponential vs power-law. Smallville decays memory exponentially (constant half-life); human forgetting is power-law (fast, then flattens — old memories persist). The exponential is the classic simplification that fits worse.
  2. Structure — one scalar vs a sum over every access. Smallville's recency is a single “hours since last access” number; ACT-R's base-level is the log of a sum over every past access, each decaying by its own age — memory as a continuously-replenished superposition, not one countdown.
  3. Weighting — equal (α=1) vs attention-weighted. Smallville weights the three terms equally; ACT-R's W terms mean they are not equal. Setting all α=1 denies that.

The wild read says “the decay constant is hand-tuned — vary it.” The seeded critic says “it's the wrong functional form.” That is the difference between tune the knob and the knob is the wrong shape — and it only exists because the panel had a seeded rival model to stand on.

And the paradigm-exit critics — the ones that step outside the paper's frame

  • Suchman — the plan→react→reflect loop is post-hoc rationalization, not situated action.
  • Weizenbaum — the believability metric is the ELIZA effect.
  • Turing — his own game, doubting that “passing = being.”
  • Blake — “the metric and the generator share the same bias”: an LLM is optimized to emit the plausible, and believability rewards the plausible — so the huge effect may be plausibility grading plausibility.

Every wild-found gap lives inside the paper's frame; these step outside it. That, plus auditable multi-panel disagreement, is the seeded instrument's contribution.

One honest caveat. Smallville uses 0.995 as an engineering retrieval weight, not explicitly as a human-forgetting model — so the critique bites because the paper frames its agents as simulating human behavior. If you claim human-likeness, the memory term should match the human data; it doesn't. (The ACT-R equations should be re-verified against Anderson before print.)

The bodyWhat a strong wild read also finds

These six gaps are real and defensible — but a strong cold read surfaces them too, so they're the body, not the headline. Each still carries its discriminating experiment (the gap → the test that resolves it); the first two are the fullest.

G1The d = 8.16 measurement artifact

The headline effect size uses TrueSkill's posterior σ (an estimator-uncertainty that shrinks with more comparisons) as Cohen's d denominator — not the outcome SD — manufacturing “eight SD.” And d doesn't reproduce from the reported μ/σ (recomputes ≈ 12.2).

Discriminating experiment

Recompute a distributional effect size — Cliff's δ or CLES — on the raw rank matrix already collected. If the huge separation vanishes, the headline number was an artifact of the wrong denominator.

G2The ablation confound — behavior vs Q&A read-access

The ablations were never re-simulated: every condition answered off the full architecture's memory stream, access throttled only at question time (§6.2). So “each component contributes critically to behavior” is measured on read-access, not lived behavior.

Discriminating experiment

Re-simulate each ablation end-to-end, K ≥ 5 seeds, and rank the behavior replays — not the interviews. If the gap collapses, the original result measured Q&A read-access.

G3Construct validity

“Believability” is operationalized as interview-answering — how the agent talks about itself — not as behavior. The metric may be measuring the narrator, not the architecture.

Discriminating experiment

Two-arm measurement on the same replays: (a) the current interview-ranking; (b) a behavior-only believability instrument (Riedl & Young objective character-believability, or forced-choice human-vs-agent behavior-trace discrimination), evaluators blind to the memory stream. Outcome: high correlation → the interview proxy is valid; divergence → the paper measured Q&A consistency, and behavioral believability is unestablished.

G4Emergence is n = 1

The emergent-behavior claims (the party, the diffusion of information) rest on a single run, with no control condition or null model.

Discriminating experiment

Re-measure diffusion / relationship-formation / coordination on (i) the fully-ablated “no-memory” swarm and (ii) a memoryless-but-chatty LLM-agent swarm — same seeds, same user-seeded intents, K seeds — compare curves with CIs. Outcome: Full ≫ controls → architecture-driven; controls also diffuse → a generic LLM-chatter property.

G5Retrieval magic-constants + the wrong forgetting form

The recency/importance/relevance constants (0.995, α=1, the 150 reflection threshold) carry the system with no derivation — and the exponential recency decay is the form the ACT-R critic (above) contests.

Discriminating experiment

Replace exponential recency with ACT-R base-level activation (power-law, attention-weighted); free the α weights and the 0.995 / threshold-150 constants via grid-fit; run the omitted sensitivity sweep; measure retrieval quality + downstream believability. Outcome: ACT-R ≥ exponential → the ad-hoc constants are unmotivated; exponential wins/ties → the simple form is defensible and now calibrated.

G6Irreproducible model

An unpinned gpt-3.5-turbo, no seed or temperature reported, and a single run — the result cannot be reproduced as specified.

Discriminating experiment

Re-run with a pinned model snapshot, fixed temperature, and logged seeds — K ≥ 5 independent 2-day sims; report between-run SD; repeat on a second model. Outcome: low SD → single-run estimates were safe; high SD → every headline number needs CIs; second-model divergence → believability tracks the LLM, not the architecture.

Runner-up — strawman baselines. The “prior work” condition is the authors' own fully-gutted system, and the human baseline is explicitly non-maximal — the comparison is stacked before the architecture is tested.

Honest flagsWhat the scan says about itself (§13)

  • The d-arithmetic discrepancy is a doesn't-reproduce flag, not a proven error — the d-scale is unstated.
  • The G2 / G4 re-simulation tests are expensive-but-decisive — and cost is the paper's own stated blocker.
  • G3 / G5 assume a believability scorer cheap enough to run at sweep scale.
  • The ablation-confound and weak-baseline points are partly self-acknowledged by the authors (§6.2). The gap is that the headline framing doesn't carry those caveats.
  • The honest baseline finding itself: on a tech paper (the LLM's home turf) a strong wild read matches the instrument at gap-finding. The instrument's edge is the seeded rival model + the paradigm critique + auditable disagreement — not the find.
