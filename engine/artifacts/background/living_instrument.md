# The one-sentence claim
The instrument is **not a static pipeline** — it is a **living object that improves from its own test feedback.** Every
test (A/B, reflexive/IRR224, future panels) feeds a backlog of candidate improvements; candidates graduate by recurrence +
validation; the instrument is rebuilt and re-tested. This *living-method* property is itself a thesis-grade contribution
(and the story that lands with an advisor: "here is the instrument improving itself, and here is the backlog proving it").

# The four pieces (all captured + committed S156)
### 1 · A LAYERED gap-model — gaps live at four layers, not only in the grammar
The instrument SITUATES (Sitz · Paradigm · Frame) then ANALYZES (moves). Gaps can live at ANY of these layers:
- **Sitz-gap** — unresolved in the historical-material conditions (dating, authorship, audience, **translation/transmission**)
- **Paradigm-gap** — unresolved in the operating logic / mode of reasoning
- **Frame-gap** — unresolved in the framing / vantage / **reading-level (genre)**
- **Move-gap** — the current 3 loci (grammar-slot / frame-role / edge) — the only layer we scanned before S156
→ detail: `pm/50_audits/layered_gap_model_and_wild_ledger_s156_2026-07-30.md`

### 2 · A WILD-ARM discovery loop — a mechanism for finding what the instrument doesn't ask
A blind A/B (same model, ± the instrument) uses the *cold* read as a **discovery mechanism**: whatever the wild arm finds
that the instrument misses is a candidate new locus. A running ledger logs these, tagged by layer; a candidate graduates
when it RECURS across texts (fit-or-extend). Already surfaced: **translation/transmission (4 of 5 texts)** = the strongest
new candidate; genre + narrator-reliability (Frame); mode-of-reasoning (Paradigm).
→ detail: `pm/50_audits/AB_protocol_instrument_vs_wild_...` + `AB_synthesis_jonah4_...` + `AB_battery_wild_arms_...`

### 3 · A MASTER improvement backlog — the single store of record for iteration
Every test's candidates in ONE place (§2.13), tagged by source-test · layer · recurrence · disposition, with a graduation
rule (recur + validate → CLC lock). Already merges the A/B fixes (ranking bug, Situate-foreclosure, full-inventory) AND the
IRR224 reflexive findings (gap-bounding, the agentive-ontology strain, the missing tone track, the Sitz-relevance rule).
→ detail: `pm/50_audits/INSTRUMENT_IMPROVEMENT_BACKLOG_master_2026-07-30.md`

### 4 · The output FEEDING-GRAPH — outputs feed gaps, gloss, and each other
Outputs are a directed graph, not a flat menu. **Detectors** feed the gap-scan (RESITUATE→gaps; Compare→cross-account
gaps); **Validators** confirm gaps (Reception↔gaps, the Romans-8:29 test); **Enrichers** feed the gloss; **Composers** feed
each other (Reception+Compare = the reception-chain). This gives the new Sitz/Frame layers a working detector (RESITUATE)
already.
→ detail: `pm/50_audits/output_feeding_graph_s156_2026-07-30.md`

# How the pieces connect (the loop)
```
test (declares purpose + improvement-payoff)
  → wild-arm/reflexive discovery  → candidate (tagged by LAYER)  → MASTER BACKLOG
  → graduate (recurrence + 5IRR)  → CLC lock  → build into next instrument version
  → re-test  → (new candidates)  → …
```
The layered gap-model (1) says WHERE gaps live; the discovery loop (2) FINDS new loci; the backlog (3) TRACKS them; the
feeding-graph (4) shows which outputs can DETECT/ENRICH/VALIDATE. Together: a method that gets better every time it runs.

# Thesis framing (why this matters beyond engineering)
This is §2.14 (test the instrument out of domain — the battery spans traditions/formats) + §2.15 (diverge→converge: the
wild arm goes wide, the instrument consolidates; the discovery loop is the diverge, the backlog the converge) + §2.8 (honest

say so). The living-instrument property turns "is your method any good?" into "here is my method improving itself, audited."
