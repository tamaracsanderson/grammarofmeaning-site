# Lineage — crit log (matrix + watershed)

**Figures:** `_staging/viz_lineage_matrix.html` · `_staging/viz_lineage_watershed.html`
**Question:** *where does Mark 16 draw on prior tradition — and what does that borrowing leave unsaid?* ("The Seam".)
**PI + GPT crit 2026-08-14.** Research value 4.5/5; the fix is hierarchy + connection-back-to-the-text, not the idea.

## PI notes — matrix
1. **Seam is below the fold** — it's the interpretive payoff; move it into a **persistent selected-relation inspector** (travels with the selected relation).
2. **Harvey balls are the wrong metaphor** — ○◐● reads as *degree/partial*, but quotation/echo/allusion are **kinds**, not amounts. Echo ≠ half a quotation. → **relation type changes SHAPE (or letter Q/E/A); confidence changes opacity** (orthogonal axes).
3. **Only M#, no Mark text** — can't connect "Isaiah 53 → M13" without seeing what M13 says. Show the move text on hover/select.

## PI notes — watershed ("I do like this idea")
4. **Text overlap** — "early Christian" label collides with "MARK 16".
5. **"Luke" not "synoptic gospel"** — name the specific source at the tributary/node (the trunk can stay family-level; the leaf must be specific: Luke 8:2, Isaiah 53). Same as GPT #11: "Isaiah 53 → M13", not "Hebrew-Bible → M13".
6. **Can't connect the two** — the seam (source) is below the fold and the Mark move text isn't present.
7. **"What is early Christian?"** — the "other early-Christian" family is undefined; say what's in it (pre-Pauline formulae / creedal material / etc.).

## GPT crit — 8 priorities
1. **Seam → persistent selected-relation inspector** (not scroll-to-bottom).
2. **Replace Harvey balls with categorical marks** (Q/E/A, or distinct geometry — not fractional).
3. **Every M-number reveals the actual Mark move** on hover/focus.
4. **On select, show BOTH sides** — `Luke 8:2 → M25` with source + Mark text, matching material highlighted (so you can *see* why the relation was proposed, esp. for unmarked echo/allusion). Overview glyph = category; inspector = evidence.
5. **FUNCTION more prominent** — scaffold/authorize/transform (why it matters) over source-family (where from). Filter the passage by function.
6. **Spine = overview ("where"); matrix = drill-down ("from where/what kind"); inspector+seam = "so what"** — one interactive drill-down (3 zoom levels), not three stacked report sections.
7. **Negative-space caution** — "no coded upstream" ≠ "no upstream exists". Soften "the negative space is the finding" → **"the negative space is itself data / a finding to investigate."** Distinguish `lineage coded` / `assessed, none found` / `not yet assessed`.
8. **Textual evidence one click away** (Mark wording ↔ source wording, highlighted).
- Define "The Seam" in one sentence somewhere: *the unresolved question created where inherited material is taken up but not fully carried over or explained.*
- Reorder the seam card: **meaning before coding apparatus** (source→M#, what Mark draws, what remains open, THEN the badges).
- Counts clarity: "16/55 moves have ≥1 coded upstream · 7/55 explicit quotation · 17 family→move reaches (one move may be reached by >1 family)".
