Grammar of Meaning · reading-room house pattern · S159

A reading room, shown.

A reading room is a template, not a page. One skeleton, one skin — swap the tradition config (icon · backgrounds · music · movements · voices) and the room feels native, not reskinned.

The feeling to hit: a coffee-table book that comes to life. North star: Taschen · Assouline · Rizzoli · Phaidon · Gestalten. Below, every part is shown as a specimen you can copy.

A · the defining move

Two grounds, one palette

The single thing that keeps the new pages + the current pages reading as one book: name the pattern as one system with two grounds. The paper ground is where you read (warm, vellum + linen texture — the tactility). The plate ground is where art breathes (deep near-black, so the plate glows). Same accent golds/greens on both — so switching rooms feels like turning a page.

F · the swappable layer

The tradition config — swap it, get a native room

Everything a new tradition needs is a config object (DATA — a JSON the page renders from, never hardcoded). A Buddhist / Sufi / Yoruba room = the same skeleton with its own icon, movements, chant, art, figures.

tradition = {
  id: "gospels",  name: "The Gospels",  tagline: "Four accounts · one door",
  hero_icon: "christ-pantocrator.jpg",
  accent:  { gold:"#B08A3C", green:"#2C4A38" },     // optional per-tradition tint
  background_pool: [ "plate-nativity.jpg", ... ],   // rotating landing backgrounds
  music_manifest:  [ {title, tradition, performer, src, license, credit_line}, ... ],
  movements: [ { numeral:"I", title:"NATIVITY", label:"ADVENTUS", refs:"MT 1–2 · LK 1–2",
                 one_line:"A birth reported by two witnesses and passed over in silence…",
                 plate:"adoration-shepherds.jpg", caption:"…CA. 1605–10 · THE MET" }, ... ],
  voices: [ {name:"Matthew", emblem:"matthew-angel.svg"}, ... ],
}
