The Reading-Room House Pattern

A reading room is a TEMPLATE, not a page. One fixed skeleton + one swappable tradition config. Build the Gospels room once; spin up a Buddhist / Sufi / Yoruba room by swapping the config — and each feels native, not reskinned.

The feeling to hit: a coffee-table book that comes to life. North star (fine-art / luxury publishers): Taschen · Assouline · Rizzoli · Phaidon · Gestalten.

1 · The two grounds

The single move that keeps the new Lovable pages + the current pages reading as one site — not two — is to name the pattern as one system with two grounds:

GroundWhereTexture
PAPERreading surfaces — landing, essays, braid, the reading itselfvellum / linen fiber overlay — the tactility. This is where vellum/linen lives (you confirmed) — NOT the gallery.
PLATEart galleries — the Night Gallery TOC, art displaysnone — clean deep-black so the plates glow

The same accent palette (moss/fern green · illuminated gold · terracotta) ties both grounds, so moving from a dark gallery to a paper reading page feels like turning a page in one book. That shared palette is the coherence guarantee.

2 · The fixed skeleton shared by every tradition

Type system

Fraunces (display — the illuminated titles) · Newsreader (serif reading) · Inter (UI) · IBM Plex Mono (eyebrows + museum captions). The existing GoM reading-room stack.

The "coffee-table-alive" elements

  • Material texture — the vellum/linen fiber overlay on the PAPER ground. The biggest single "comes-to-life" lever.
  • The plate-frame — art gets a thin gold border + soft inner shadow (the Assouline/Taschen "the object is precious" treatment).
  • Illuminated moments — gold drop-caps, hairline gold rules, Roman-numeral movement markers, Latin/native names (ADVENTUS · DESERTUM).
  • Slow reveal — plates fade / gently parallax in on scroll; restrained (Phaidon-minimal). Always prefers-reduced-motion-aware.
  • The caption voice — mono, museum-label ("THE ADORATION OF THE SHEPHERDS, CA. 1605–10 · THE MET"), with provenance + license, always credited.

3 · The tradition config the swappable layer — the point

Everything a new tradition-room needs to feel native is a config object. Swap it → new room. Nothing else changes.

tradition = {
  id: "gospels",  name: "The Gospels",  tagline: "Four accounts · one door",
  hero_icon: "christ-pantocrator.jpg",        // the landing icon
  accent:    { gold:"#B08A3C", green:"#2C4A38" },  // optional per-tradition tint
  background_pool: [ "plate-nativity.jpg", ... ],  // rotating landing backgrounds
  music_manifest:  [ {title, tradition, performer, src, license, credit_line}, ... ],
                   // Librarian-sourced, open-license, credited
  movements: [ { numeral:"I", title:"NATIVITY", label:"ADVENTUS",
                 refs:"MT 1–2 · LK 1–2",
                 one_line:"A birth reported by two witnesses and passed
                           over in silence by two others.",
                 plate:"adoration-shepherds.jpg",
                 caption:"THE ADORATION OF THE SHEPHERDS, CA. 1605–10 · THE MET" }, ... ],
  voices: [ {name:"Matthew", emblem:"matthew-angel.svg"}, ... ],
}

The Gospels room = this config, filled. A Buddhist room = the same skeleton with its own icon, movements, chant traditions, art, and figures. The experience (dark gallery, illuminated plates, ambient sound, slow reveal, museum captions) is identical; the content is native.

4 · Fixed vs. swappable — the contract

LayerFixed (the house)Swappable (the config)
Type system✓ Fraunces/Newsreader/Inter/Mono—
Two grounds + palette✓ paper + plateaccent tint only
Alive-elements✓ texture · frame · illumination · reveal · caption—
Interactions✓ theme · player · scroll · keyboard—
Hero icon—✓ hero_icon
Backgrounds—✓ background_pool
Music—✓ music_manifest
Movements / TOC—✓ movements
Voices / figures—✓ voices

The config is DATA — a JSON the page renders from, never hardcoded (same discipline as the library/method pages). Change the tradition → change the config → the room re-renders. This is what makes the reading room a repeatable instrument, not a bespoke page.
