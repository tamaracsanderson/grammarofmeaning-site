A reading room, shown

A reading room is a template, not a page. One skeleton, one skin — swap the tradition config (icon · backgrounds · music · movements · voices) and the room feels native, not reskinned.

Fonts + frame treatment are ported from your Lovable mock — Cormorant Garamond + IBM Plex Mono, the "night skin" (real artwork + drop-shadow + slow hover-lift; frames hang straight). North star: Taschen · Assouline · Rizzoli · Phaidon · Gestalten. Hover the paintings.

A · the defining move

Two grounds, one palette

The single thing that keeps the new pages + the current pages reading as one book: one system, two grounds. The paper ground is where you read (warm, vellum + linen texture). The plate ground is where art breathes (the night wash, so the painting glows and casts a real shadow). Same accent golds/greens on both.

n the beginning was the reading. The paper ground carries warmth and grain — a low vellum noise with a faint linen weave, so the page feels held, not screen-lit. F · the swappable layer

The tradition config — swap it, get a native room

Everything a new tradition needs is a config object (DATA the page renders from, never hardcoded). This IS the mock's MOVEMENTS array — I port it directly. A Buddhist / Sufi / Yoruba room = the same skeleton with its own icon, movements, chant, art, figures.

tradition = {
  id: "gospels",  name: "The Gospels",  tagline: "Four accounts · one door",
  hero_icon: "christ-pantocrator.jpg",
  background_pool: [ ... ],                          // rotating landing backgrounds
  music_manifest:  [ {title, tradition, performer, src, license, credit}, ... ],
  movements: [
    { n:"I",  title:"Nativity",     latin:"Adventus",  refs:"Mt 1–2 · Lk 1–2",
      line:"A birth reported by two witnesses and passed over in silence by two others.",
      img:"…/DP123919.jpg", credit:"The Adoration of the Shepherds, ca. 1605–10 · The Met" },
    { n:"II", title:"Wilderness",   latin:"Desertum",  refs:"Mk 1 · Mt 3–4 · Lk 3–4",  … },
    { n:"III",title:"Teaching",     latin:"Doctrina",  … },   // Christ and the Adulteress · The Met
    { n:"IV", title:"Signs",        latin:"Signa",     … },   // Marriage Feast at Cana · The Met
    { n:"V",  title:"Passion",      latin:"Passio",    … },   // Crucifixion; Last Judgment · The Met
    { n:"VI", title:"Resurrection", latin:"Resurrectio", … }, // German diptych, 1300–1325 · The Met
  ],
  voices: [ {name:"Matthew", emblem:"matthew-angel.svg"}, … ],
}
