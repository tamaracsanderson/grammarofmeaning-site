How to read this

Each row is a move, top to bottom in reading order. Click a move to trace its links: an arc bends out from it to each move it connects to — the farther the arc reaches, the farther across the passage the connection runs. The panel names each connection in plain language. Plain sequence (“and then”) is hidden by default — the reading order already shows it. This view shows linkage only (how the moves hold together); the few shape echoes live in another view.
